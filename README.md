# Arnai Plugins (gratis)

9 plugins VST3 para Windows de 64 bits, hechos por ARNAI LAB.

- **Voz:** Arnai Voz Strip, Arnai De-Esser, Arnai Limit, Arnai Loudness, Arnai Pop, Arnai Voz Denoise, Arnai Breath, Arnai Vozboard
- **Guitarra:** Arnaiboard Guitar

## Descarga

**[⬇ Descargar Arnai Plugins v1.2 (.zip)](https://github.com/arndev10/arnai-plugins-free/releases/download/v1.2/Arnai-Plugins-v1.2.zip)**

## Instalación

1. Descomprime el zip.
2. Copia las 9 carpetas de `VST3\` (cada una termina en `.vst3`; cópialas enteras) a `C:\Program Files\Common Files\VST3`
   (sin permisos de administrador: `%LOCALAPPDATA%\Programs\Common\VST3`).
3. En Reaper: Options > Preferences > Plug-ins > VST > Re-scan. Busca "Arnai".
4. Abre `Manual Arnai.pdf`: la sección 2 muestra las cadenas completas para grabar y para mezclar.

Si Reaper los ve pero no cargan: instala "Microsoft Visual C++ Redistributable x64".
